# Confluens

Sistema de gestión de eventos y servicios gastronómicos para **Los Abuelos Servicios Gastronómicos SRL**. Centraliza el ciclo completo de un evento en sus cinco salones (Paraná, Iguazú, Pucará, Bariloche y Auditorio) y en el comedor: consulta, presupuesto, prereserva, confirmación, comanda de cocina y cobro.

Proyecto de Seminario Integrador, UTN FRC. Equipo de 7 personas, Scrum con sprints de 2 semanas.

Esta carpeta es también el vault de Obsidian del equipo: todo es markdown plano con links relativos.
